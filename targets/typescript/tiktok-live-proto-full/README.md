# @eulerstream/tiktok-live-proto-full

Private TypeScript bindings for the **full** TikTok Webcast Protobuf schema.

Distributed via GitHub Packages — only accessible to EulerStream org members.

## Install

Configure auth for `@eulerstream` against GitHub Packages, then:

```sh
npm install @eulerstream/tiktok-live-proto-full
```

`.npmrc` (per-project):

```
@eulerstream:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

## Usage

```ts
import { WebcastResponse } from '@eulerstream/tiktok-live-proto-full/v1';
import { WebcastResponse as WebcastResponseV2 } from '@eulerstream/tiktok-live-proto-full/v2';
```

The correct runtime build (Node vs. browser) is selected automatically by the
resolver via the `exports` conditions.

## Layout

- `src/full/v1/**/*.proto`, `src/full/v2/**/*.proto` (private submodule at the
  repo root) — canonical schemas
- `targets/typescript/tiktok-live-proto-full/src/generated/{v1,v2}.ts` —
  generated by `ts-proto`, committed to the repo, regenerated by CI when any
  `.proto` under `src/full/` changes
- `dist/{node,web}/{v1,v2}.*` — bundled output, produced by `tsdown`,
  not committed
