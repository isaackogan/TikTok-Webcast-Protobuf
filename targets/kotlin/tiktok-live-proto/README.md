# tiktok-live-proto (Kotlin / JVM)

Kotlin/JVM bindings for the slim TikTok Webcast Protobuf schema, generated by
[Square Wire](https://square.github.io/wire/). Idiomatic data classes, no
`com.google.protobuf` runtime dependency.

## Layout

- `src/slim/v{1,2,3}/**/*.proto` (in the repo root) — canonical schemas
- `scripts/prepare_protos.py` — staging step. Two paths:
  - **Legacy (v1, v2)**: merges all .proto files in the version into one
    `tiktok-schema.proto` (resolves v2's implicit cross-file references) and
    sets `package tiktok.<version>;` to keep v1/v2 namespaces distinct.
  - **Modern (v3+)**: copies files preserving the original layout; injects
    `option java_package` per file to land classes under
    `io.github.isaackogan.tiktok.v3.<original.proto.package>`.
- `build/generated/source/wire/**/*.kt` — Wire output. Not committed; rebuilt
  on every `./gradlew build`.

## Build

```sh
./gradlew build
```

Requires Python 3.10+ on `PATH` (for the proto staging step).

## Kotlin packages produced

| Schema | Kotlin package |

| ... | ... |

## Publish

`publishing` is parameterised on `MAVEN_REPO_URL` (defaults to the EulerStream
Cloudsmith Maven repo). Override at deploy time:

```sh
MAVEN_REPO_URL=https://your.repo/maven/ \
MAVEN_USERNAME=... MAVEN_PASSWORD=... \
./gradlew publish
```

CI populates these from the `MAVEN_USERNAME` / `MAVEN_PASSWORD` GitHub
secrets.
