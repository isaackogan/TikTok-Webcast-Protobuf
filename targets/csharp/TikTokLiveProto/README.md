# TikTokLiveProto

C# / [Google.Protobuf](https://www.nuget.org/packages/Google.Protobuf) bindings for the [TikTok Webcast Protobuf](https://github.com/isaackogan/TikTok-Webcast-Protobuf) schema.

## Install

```sh
dotnet add package TikTokLiveProto
```

Targets: `netstandard2.0`, `netstandard2.1`, `net8.0`, `net9.0`, `net10.0`.

## Usage

Import the version you need via its namespace:

```csharp
// v1 schema
using TikTokLiveProto.V1;

// v2 schema
using TikTokLiveProto.V2;

// v3 schema
using TikTokLiveProto.V3.Webcast;
using TikTokLiveProto.V3.Webcast.Model.Message;
using TikTokLiveProto.V3.Webcast.Shared;
```

All three versions ship in the same assembly. Namespaces keep them isolated so
there are no collisions even when you import multiple versions at once.

### Example — parsing a Webcast push frame (v3)

```csharp
using Google.Protobuf;
using TikTokLiveProto.V3.Webcast;
using TikTokLiveProto.V3.Webcast.Model.Message;
using TikTokLiveProto.V3.Webcast.Shared;

// Outer transport frame
var frame = WebcastPushFrame.Parser.ParseFrom(rawBytes);

// Inner fetch result (contains the list of messages)
var result = ProtoMessageFetchResult.Parser.ParseFrom(frame.Payload);

foreach (var msg in result.Messages)
{
    if (msg.Method == nameof(WebcastChatMessage))
    {
        var chat = WebcastChatMessage.Parser.ParseFrom(msg.Payload);
        Console.WriteLine($"{chat.User?.Nickname}: {chat.Content}");
    }
}
```

### Namespace map (v3)

| Proto package | C# namespace |
|---|---|
| `webcast` | `TikTokLiveProto.V3.Webcast` |
| `webcast.shared` | `TikTokLiveProto.V3.Webcast.Shared` |
| `webcast.model` | `TikTokLiveProto.V3.Webcast.Model` |
| `webcast.model.base` | `TikTokLiveProto.V3.Webcast.Model.Base` |
| `webcast.model.message` | `TikTokLiveProto.V3.Webcast.Model.Message` |
| `webcast.model.gift` | `TikTokLiveProto.V3.Webcast.Model` |
| `webcast.model.data` | `TikTokLiveProto.V3.Webcast.Model.Data` |

## Layout

- `src/slim/v1/**/*.proto`, `src/slim/v2/**/*.proto`, `src/slim/v3/**/*.proto` (repo root) — canonical schemas
- `targets/csharp/TikTokLiveProto/src/generated/{v1,v2,v3}/` — generated by `protoc` + `grpc-csharp-plugin`, committed to the repo, regenerated by CI when any `.proto` under `src/slim/` changes

## Regenerating

```sh
cd targets/csharp/TikTokLiveProto
python scripts/generate.py
```
